# IWIP Complete Responsive Website

Website multi-page untuk GitHub Pages, compatible desktop dan mobile.

## File
- index.html
- about.html
- news.html
- career.html
- esg.html
- gallery.html
- contact.html
- styles.css
- script.js

## Fitur
- Navbar responsive
- Multi-page website
- Search overlay
- Dark mode
- Filter news
- Filter career
- Form apply simulasi
- Form contact simulasi
- Galeri fullscreen preview
- Modal popup
- Counter animation
- Scroll reveal animation
- Back to top
- Compatible desktop dan mobile

## Upload GitHub Pages
Upload semua file ke root repository.
Settings > Pages > Branch main > /root > Save
